# Hi, I'm Erik 👋

Senior C++ engineer at **Samsung Research** (Tijuana, Mexico). For the past 8 years I've built
video and image processing software, GPU compute pipelines, and Qt desktop tools that talk
directly to hardware.

### What I work on

- **Video & image processing** — per-frame algorithms (color correction, scaling, noise
  reduction, sharpening, tone mapping, LUTs) on decoded video across color spaces, bit depths,
  and resolutions up to 4K
- **GPU compute** — porting CPU-bound image algorithms to asynchronous OpenCL kernels, and
  GPU buffer management across parallel execution paths
- **Hardware integration** — device-control stacks over RS-232/UART built from vendor protocol
  specifications, plus integration with color-measurement instruments and depth cameras
- **Qt desktop tooling** — multithreaded applications, Graphics View, custom painting,
  model/view
- **Color science** — gamma/EOTF, HDR10, Delta-E, LUT generation, image quality metrics
- **Developer tooling** — a pull-request review pipeline combining static analysis
  (clang-tidy, cppcheck) with AI agents
